HYBRID STACKING MODEL FOR MULTIVARIATE DETECTION OF DDoS, SYBIL, BLACKHOLE ATTACKS IN VANETs

OVERVIEW
This project focuses on developing an intelligent detection system for Vehicular Ad Hoc Networks (VANETs) using a Hybrid Stacked TAO Tree Classifier. The proposed model is designed to detect and classify multiple cyber-attacks such as DDoS, Sybil, and Blackhole attacks to enhance the security, reliability, and efficiency of vehicular communication systems.
The system combines the strengths of multiple machine learning algorithms, including K Nearest Neighbours ,Naive Bayes classifier  and Support Vector Classifier (SVC), within a stacked ensemble framework to improve prediction accuracy and minimize false detection rates.

OBJECTIVES
  Detect malicious activities in VANET environments
  Improve network security and communication reliability
  Reduce false positives and enhance detection accuracy
  Handle imbalanced datasets efficiently
  Compare the performance of hybrid and individual models
